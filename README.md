## 分目录说明

- Constrained Trajectory Optimization for Complex Robotics Systems
- 移动机器人人居环境类人导航、四足机器人、DeepSeek 入门等

### 教材
按方向分 6 类，收录领域经典书：

### 论文

### SLAM

- 应用：SLAM 技术在自动驾驶中的应用与难点（智行者）

## 维护约定

- **更新方式**：把新资料拷进对应目录，然后
  ```bash
  git -C ~/repos/Documents add -A
  git -C ~/repos/Documents commit -m "新增 xxx"
  git -C ~/repos/Documents push
  ```
  （本仓库的 git 数据与文件本体分离存放，命令需在 `~/repos/Documents` 执行）
- 超过 100 MB 的单个文件无法入库（GitHub 限制），保留本地并记入 `.gitignore`
